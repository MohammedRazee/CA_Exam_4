# CA Lab Test — Q4: Custom Modules

## Task

Create a module `mathOps.js` that exports four functions: `add`, `subtract`, `multiply`, and `divide` (named or default exports — your choice).

In `index.js`, import these functions and:
a) Print the sum, difference, product, and quotient of two numbers of your choice.
b) Using **only the imported functions** (no direct `+`, `-`, `*`, `/` operators in this part), compute and print the result of `((a + b) * (a - b)) / 2`.
